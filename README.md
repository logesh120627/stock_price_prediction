# Stock Price Prediction

A machine learning project that predicts stock prices using historical market data.

## Tech Stack

- Python
- yfinance (data collection)
- pandas, NumPy (data processing)
- scikit-learn (modeling)

## Project Structure

```
Stock_price_prediction/
├── data/             # Historical stock data (CSV)
├── models/           # Trained models
├── outputs/          # Predictions and charts
├── app.py            # Application entry point
├── main.py           # Data loading and model training
└── requirements.txt  # Dependencies
```

## How to Run

```bash
git clone https://github.com/logesh120627/stock_price_prediction.git
cd stock_price_prediction
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
python app.py
```
